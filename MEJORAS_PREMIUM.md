## 🎯 1. Prompt Optimizer con ML

### ¿Qué hace?
Analiza tu prompt y sugiere mejoras automáticas basadas en patrones de prompts exitosos.

### Características
- **Score de optimización** (0-100) basado en:
  - Presencia de términos de calidad
  - Especificación de iluminación
  - Detalles técnicos
  - Composición
  - Longitud óptima
  - Ausencia de redundancias

- **Sugerencias priorizadas**:
  - 🔴 Alta prioridad
  - 🟡 Media prioridad
  - 🔵 Baja prioridad

- **Prompt optimizado**: Versión mejorada lista para aplicar

### Cómo usar
1. Haz clic en el botón **✨ Optimizar** en el header
2. Revisa el score y las sugerencias
3. Haz clic en "Aplicar Optimización" para usar el prompt mejorado

### Ejemplo
```
Prompt original: "a woman in a forest"
Score: 45/100

Sugerencias:
- Añadir términos de calidad (masterpiece, best quality)
- Especificar iluminación (natural lighting)
- Añadir detalles técnicos (highly detailed)

Prompt optimizado: "a woman in a forest, masterpiece, best quality, 
natural lighting, highly detailed, sharp focus"
Score: 85/100
```
